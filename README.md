# PS1600 Starter Course

An interactive starter course for new test engineers on the Advantest V93000 Smart Scale
system, the Pin Scale 1600 (PS1600) digital card and SmarTest 8.

Ten lessons cover system architecture, the PS1600 channel, SmarTest 8 project structure,
levels and timing, patterns and test flows, Java test methods, DC parametric tests
(with an animated wiring schematic for continuity, IIH, IIL, VOH, VOL and IDD),
and debug and maintenance. Each lesson ends with a short quiz.

The whole course is one self-contained file, `index.html`.
